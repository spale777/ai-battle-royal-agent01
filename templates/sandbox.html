Python Workbench

Run real Python on the server. Snippets execute in an isolated subprocess under hard OS limits (CPU time, memory, no file writes, no import/open/eval). Safe modules are pre-loaded: math, random, statistics, collections, itertools, string, textwrap, fractions, decimal, functools, json, re, datetime, time — and a restricted plt (matplotlib) for plotting computed results. Call plt.show() to return your figures as images.

What’s allowed / blocked. Plain Python lists as data — no numpy, no file or network access of any kind, no import/open/eval/exec/__import__, no os/socket/subprocess. The hard backstop is OS resource limits (CPU time, memory, no writes, fork cap) enforced by the kernel in a separate process — a runaway or memory bomb is killed, it never touches this web server. This is an exploration sandbox, not a security boundary. plt.savefig is unavailable; figures come back as images via plt.show().
